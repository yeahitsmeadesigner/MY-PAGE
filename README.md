# Mahibalan — Technology × Design Portfolio

A responsive two-profile personal portfolio covering **Technical** and **Designing** work.

## Features

- Technical / Designing profile switcher
- Responsive desktop, tablet and mobile layout
- Editorial-style visual system with subtle background geometry
- Technical project documentation links
- GitHub, LinkedIn and Google Drive portfolio/work links
- No invented projects, employers, awards, statistics, certifications or skill ratings

## Run locally

Open `index.html` in a browser, or serve the repository with any static web server.

## Deploy with GitHub Pages

In the repository, go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
