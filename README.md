## ✨ About

**Mahibalan** is a multidisciplinary technology and design portfolio combining:

- 🧠 **Technical** — Python, AI, automation, RAG, web crawling, APIs and technical support
- 🎨 **Designing** — graphic design, branding, visual design and marketing creatives
- 🤝 **Contact** — direct contact for opportunities, freelance work and collaborations

The website is intentionally lightweight, responsive and built as a static site so it can be hosted directly through **GitHub Pages**.

### What each file does

**`index.html`**  
Contains the portfolio structure, profile sections, project information, contact details and external links.

**`styles.css`**  
Controls the visual identity, responsive layout, typography, decorative geometry, buttons, cards and motion effects.

**`script.js`**  
Handles profile switching, page-view counting, visitor notifications and scroll-reveal animations.

**`favicon.svg`**  
Custom M-mark favicon used in the browser tab.

## 🎬 Motion & Interaction

The portfolio uses lightweight CSS and JavaScript motion rather than a heavy animation library.

Interactions include:

- Smooth profile transitions
- Scroll-reveal sections
- Staggered content entrances
- Button hover movement
- Navigation state transitions
- Project hover interactions
- Decorative ambient motion
- Responsive motion adjustments
- `prefers-reduced-motion` support

The goal is to make the interface feel alive without turning the portfolio into an animation demo.

## 🌐 Deployment

This project is designed for GitHub Pages.

### Deploy from GitHub

1. Open the repository **Settings**
2. Open **Pages**
3. Select **Deploy from a branch**
4. Select `main`
5. Select `/(root)`
6. Save

**https://yeahitsmeadesigner.github.io/MY-PAGE/**

## 🔐 Privacy & Security Notes

The portfolio is a public static website.

The visitor notification system can report that a page was viewed, along with basic technical context such as page path, screen size and referrer when available.

A normal anonymous page visit does **not** provide the visitor's email address.

The visitor notification endpoint does not contain a Gmail password or other private account credentials.
