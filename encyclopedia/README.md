# Mahibalan S — Personal Encyclopedia

A responsive, single-file, Wikipedia-inspired personal profile page.

## Preview locally
Open `index.html` in any modern browser.

## Live page
https://yeahitsmeadesigner.github.io/MY-PAGE/encyclopedia/

## Publish with GitHub Pages
The parent `MY-PAGE` repository is already configured as a GitHub Pages site. This folder is served as a subpath of that site.

## Personalisation
- Replace the `M` portrait placeholder with a photo if desired.
- Review all dates, project descriptions and skill claims before publishing.
- Add or remove external links in the Notes section.
- The page intentionally avoids publishing a phone number or personal email address.

Built with plain HTML, CSS and JavaScript. No build step or external libraries are required.
